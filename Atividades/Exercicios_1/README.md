# 📝 Lista de Exercícios 1

Lista de exercícios introdutórios em Java, com entrada de dados via `Scanner`: soma de números, cálculo de médias (aritmética e ponderada) e cálculo de salários (reajuste fixo, reajuste percentual e desconto de imposto). O enunciado original está em `AT1-N1-Classe Scanner.pdf`.

## 📂 Arquivos

| Arquivo | Descrição |
|---|---|
| `Soma.java` | Questão 1 — soma de 4 números lidos via `Scanner` |
| `MediaTres.java` | Questão 2 — média aritmética de 3 números |
| `MediaPonderada.java` | Questão 3 — média ponderada de 3 notas com pesos |
| `SalarioVinteCinco.java` | Questão 4 — aumento fixo de 25% sobre o salário |
| `SalarioAumento.java` | Questão 5 — aumento de salário com percentual variável |
| `SalarioBase.java` | Questão 6 — cálculo de salário bruto/líquido com gratificação e imposto |
| `Main.java` | Classe `main` que executa as seis questões em sequência |
