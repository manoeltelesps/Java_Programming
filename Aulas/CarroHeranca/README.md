# 🚗 Carro e Pessoa

Exercício simples de herança e associação entre classes. `Carro` guarda modelo, cor, ano e estado de ligado/desligado, enquanto `Pessoa` representa o proprietário — a classe `Main` cria algumas instâncias de cada uma e demonstra a interação entre elas (por exemplo, `Carro.propietario(Pessoa p)` exibindo o nome do dono).

## 📂 Arquivos

| Arquivo | Descrição |
|---|---|
| `exemploAula/src/Carro.java` | Classe `Carro` com atributos, construtor e métodos `ligar()`/`desligar()` |
| `exemploAula/src/Pessoa.java` | Classe `Pessoa` com construtor padrão e construtor com parâmetros |
| `exemploAula/src/Main.java` | Classe `main` que instancia carros e pessoas e testa os métodos |
